把「奥灵宠图鉴」装到桌面

装好后是独立窗口，断网也能看；作者更新后，你打开就是最新版。

安卓安装包 APK

下载后直接安装（首次可能提示「未知来源」，允许即可）。App 内打开的就是线上站点， 我这边更新内容，你打开就是最新版。

⬇ 下载 APK（约 260 KB）

需要 Android 6.0 及以上。

安卓 Chrome / Edge

  1. 点右上角的 ⋮ 菜单
  2. 选「安装应用」或「添加到主屏幕」
  3. 确认后桌面就会出现图标

iPhone / iPad Safari

  1. 点底部中间的 分享 按钮（方框 + 向上箭头）
  2. 在列表里找「添加到主屏幕」
  3. 点右上角「添加」

电脑 Chrome / Edge

  1. 点地址栏右侧的「安装」图标
  2. 或按 Ctrl + Shift + A
  3. 确认后桌面和开始菜单就有图标
← 回到图鉴

如果菜单里找不到「安装」：请确认用 Chrome / Edge / Safari 打开，并且网址是 https 开头。微信、QQ 等内置浏览器不支持安装，点右上角「在浏览器中打开」即可。
